## Project discovery
- `npm test` builds TypeScript and runs the full Node test suite; fake agent executables are placed on PATH by session and CLI tests.
- Executable fixtures for the shared harness suite live under `fixtures/agents/`; Node's default test discovery tries to execute fixtures placed under `test/`.
- The existing CLI flag is `--reasoning-effort`; Codex receives it through `-c model_reasoning_effort=<JSON string>`.
- The built-in adapter registry is `src/agents/registry.ts`; CLI validation and the run loop both read it, and the session runner requires an adapter.
- Run status rendering is in `src/main.ts`; execution-error events and terminal status carry the session's `stderrTail` through `src/run.ts`.
